Gaps analysis:

These are the systems that prevent Baritone from being truly autonomous in survival. Sorted by how badly they block self-sufficiency.

No survival goal planner
Baritone is reactive, not proactive. There's no state machine that says "I need food to I need to farm to I need seeds to I need to find a village." A goal planner (HTN or GOAP-style) is the missing brain that orchestrates all other systems.
Critical blocker
Java mod layer
HTN / GOAP

No crafting system
Cannot open or use crafting tables, furnaces, blast furnaces, smokers, or any other workstation. This means raw materials never become tools, food never cooks, and ore never smelts. The entire Minecraft tech tree is blocked.
Critical blocker
Recipe graph
GUI interaction

No combat
Zero ability to fight. Can't kill a zombie blocking its path, can't farm mobs for drops (leather, bones, string), can't fight the Ender Dragon or Wither. Dies to anything that hits it with no response.
Critical blocker
Click timing
Boss logic

No hunger/health management
Doesn't monitor hunger or eat food from inventory. Starves to death on long runs. Doesn't use potions. Doesn't retreat to heal. Health management is zero-implemented.
High priority
Inventory scan
Right-click use

No chest / storage management
Cannot open chests, deposit or withdraw items. Inventory fills up and it drops valuable resources. No concept of a home base with organized storage.
High priority
GUI interaction
NBT reading

No tool / armor management
Doesn't track tool durability. Doesn't switch tools when better ones become available. Doesn't equip armor. Doesn't craft replacements when tools break. Will mine stone with a fist if its pickaxe breaks.
High priority
Durability tracking

No sleeping / bed usage
Never places or sleeps in a bed. Exposed to hostile mobs every night indefinitely. Cannot reset spawn point, so death means a long walk back.
Medium priority
Structure detection

No dimensional travel (Nether / End)
No portal building logic. No traversal through portals. Can't access the Nether for fast travel, blaze rods, or nether fortresses. The End and Ender Dragon are completely unreachable.
Mid-game blocker
Obsidian logic
Portal linking

No death recovery
Doesn't remember or rush back to its death point to recover dropped items. All accumulated resources are lost permanently on death.
Medium priority
Death pos memory

Here's the full breakdown. The key insight is that Baritone is already the hardest part  pathfinding and world navigation are solved, and solved brilliantly. What's missing is everything above that.
The three hardest additions, in order:
The goal planner is architecturally the trickiest. You need something like GOAP (Goal-Oriented Action Planning) or an HTN (Hierarchical Task Network)  a system that looks at the current world state ("I have 3 iron, no food, it's nighttime, 6 hearts") and decomposes goals recursively into Baritone commands. Without this, you're just wiring together a fixed script, not a real autonomous agent.
The crafting engine is the most tedious. Minecraft's recipe graph isn't that complex, but making a bot interact with GUIs (right-click table to slot positions to shift-click output) requires careful Mixin/event hooking inside the mod layer. You'd build a RecipeResolver class that takes a target item and outputs a dependency-ordered list of crafting steps, then a CraftingProcess that executes them one by one.
Combat is the most variable. Basic mob killing is actually doable in a week (strafe-attack-strafe loop with click timing). The Ender Dragon fight, however, is genuinely hard  it requires bow aim at moving crystals, pillar climbing, timed phases. That's where you'd likely end up with hardcoded boss scripts rather than general AI.

 // =====================================================================
 // HungerHealthProcess  (priority 10.0)
 //
 // Monitors food and health every tick. Auto-eats when hunger drops below
 // threshold (default 10 = 5 drumsticks). Flees from threats when health
 // drops below threshold (default 6 = 3 hearts).
 //
 // Key design decisions:
 //  - Temporary process: interrupts other processes, lets them resume
 //  - Highest priority (10.0): nothing is more important than survival
 //  - Fleeing takes priority over eating (can't eat while dead)
 //  - Looks straight up while eating to avoid accidental block interaction
 //  - Food detection uses DataComponents.FOOD (Minecraft 1.21+ component
 //    system)
 //  - Hostile mob detection uses Enemy interface + aggro check
 //  - Flee goal runs opposite to nearest threat at fleeDistance blocks
 //  - Eating timeout at 150 ticks (~7.5s), resets on food level change
 // =====================================================================

package baritone.process;

import baritone.Baritone;
import baritone.api.pathing.goals.Goal;
import baritone.api.pathing.goals.GoalNear;
import baritone.api.process.PathingCommand;
import baritone.api.process.PathingCommandType;
import baritone.api.utils.Rotation;
import baritone.api.utils.input.Input;
import baritone.utils.BaritoneProcessHelper;
import net.minecraft.core.BlockPos;
import net.minecraft.core.component.DataComponents;
import net.minecraft.world.entity.Entity;
import net.minecraft.world.entity.Mob;
import net.minecraft.world.entity.monster.Enemy;
import net.minecraft.world.item.ItemStack;
import net.minecraft.world.phys.Vec3;

import java.util.List;
import java.util.stream.Collectors;

public class HungerHealthProcess extends BaritoneProcessHelper {

    private State state = State.IDLE;
    private int eatTicks = 0;
    private int lastFoodLevel = 20;

    public HungerHealthProcess(Baritone baritone) {
        super(baritone);
    }

    @Override
    public boolean isActive() {
        if (ctx.player() == null || ctx.world() == null) {
            return false;
        }

        if (state == State.FLEEING) {
            return true;
        }

        if (ctx.player().getHealth() < Baritone.settings().healthFleeThreshold.value
                && hasNearbyThreat()) {
            return true;
        }

        if (ctx.player().getFoodData().getFoodLevel() < Baritone.settings().hungerThreshold.value) {
            return true;
        }

        if (state == State.EATING && ctx.player().isUsingItem()) {
            return true;
        }

        state = State.IDLE;
        return false;
    }

    @Override
    public PathingCommand onTick(boolean calcFailed, boolean isSafeToCancel) {
        float health = ctx.player().getHealth();
        int foodLevel = ctx.player().getFoodData().getFoodLevel();

        if (health < Baritone.settings().healthFleeThreshold.value && hasNearbyThreat()) {
            state = State.FLEEING;
            Goal fleeGoal = findFleeGoal();
            if (fleeGoal != null) {
                logNotification("Fleeing! Health: " + String.format("%.1f", health), false);
                return new PathingCommand(fleeGoal, PathingCommandType.SET_GOAL_AND_PATH);
            }
        }

        if (state == State.FLEEING) {
            if (!hasNearbyThreat() || ctx.player().getHealth() >= Baritone.settings().healthFleeThreshold.value + 4) {
                state = State.IDLE;
            } else {
                Goal fleeGoal = findFleeGoal();
                if (fleeGoal != null) {
                    return new PathingCommand(fleeGoal, PathingCommandType.SET_GOAL_AND_PATH);
                }
            }
        }

        if (foodLevel < Baritone.settings().hungerThreshold.value || state == State.EATING) {
            return handleEating();
        }

        state = State.IDLE;
        return new PathingCommand(null, PathingCommandType.DEFER);
    }

    private PathingCommand handleEating() {
        if (!ctx.player().isUsingItem()) {
            if (state != State.EATING) {
                if (!selectFood()) {
                    state = State.IDLE;
                    return new PathingCommand(null, PathingCommandType.DEFER);
                }
                state = State.EATING;
                eatTicks = 0;
                lastFoodLevel = ctx.player().getFoodData().getFoodLevel();
            }
            baritone.getLookBehavior().updateTarget(new Rotation(0, -90), false);
            baritone.getInputOverrideHandler().setInputForceState(Input.CLICK_RIGHT, true);
            eatTicks++;
        } else {
            baritone.getInputOverrideHandler().setInputForceState(Input.CLICK_RIGHT, true);
            eatTicks++;
        }

        int currentFood = ctx.player().getFoodData().getFoodLevel();

        if (currentFood >= Baritone.settings().hungerThreshold.value + 5) {
            stopEating();
            state = State.IDLE;
            return new PathingCommand(null, PathingCommandType.DEFER);
        }

        if (eatTicks > 150) {
            stopEating();
            state = State.IDLE;
            return new PathingCommand(null, PathingCommandType.DEFER);
        }

        if (currentFood != lastFoodLevel) {
            lastFoodLevel = currentFood;
            eatTicks = 0;
        }

        return new PathingCommand(null, PathingCommandType.REQUEST_PAUSE);
    }

    private void stopEating() {
        baritone.getInputOverrideHandler().setInputForceState(Input.CLICK_RIGHT, false);
    }

    private boolean selectFood() {
        for (int i = 0; i < 9; i++) {
            ItemStack stack = ctx.player().getInventory().getNonEquipmentItems().get(i);
            if (isFood(stack)) {
                ctx.player().getInventory().setSelectedSlot(i);
                return true;
            }
        }
        for (int i = 9; i < 36; i++) {
            ItemStack stack = ctx.player().getInventory().getNonEquipmentItems().get(i);
            if (isFood(stack)) {
                ctx.playerController().windowClick(
                        ctx.player().inventoryMenu.containerId, i, 7,
                        net.minecraft.world.inventory.ClickType.SWAP, ctx.player()
                );
                ctx.player().getInventory().setSelectedSlot(7);
                return true;
            }
        }
        return false;
    }

    private boolean isFood(ItemStack stack) {
        return !stack.isEmpty() && stack.getItem().components().has(DataComponents.FOOD);
    }

    private boolean hasNearbyThreat() {
        int range = Baritone.settings().threatRange.value;
        final double rSq = (double) range * range;
        return ctx.entitiesStream()
                .anyMatch(e -> e instanceof Mob && e.isAlive()
                        && e.distanceToSqr(ctx.player()) < rSq
                        && isHostile((Mob) e));
    }

    private boolean isHostile(Mob mob) {
        if (mob instanceof Enemy) {
            return true;
        }
        return mob.getLastHurtByMob() == ctx.player() || mob.getTarget() == ctx.player();
    }

    private Goal findFleeGoal() {
        int range = Baritone.settings().threatRange.value;
        final double rSq = (double) range * range;

        List<Entity> threats = ctx.entitiesStream()
                .filter(e -> e instanceof Mob && e.isAlive()
                        && e.distanceToSqr(ctx.player()) < rSq
                        && isHostile((Mob) e))
                .collect(Collectors.toList());

        if (threats.isEmpty()) {
            return null;
        }

        Entity closest = threats.get(0);
        double minDistSq = closest.distanceToSqr(ctx.player());
        for (int i = 1; i < threats.size(); i++) {
            double d = threats.get(i).distanceToSqr(ctx.player());
            if (d < minDistSq) {
                minDistSq = d;
                closest = threats.get(i);
            }
        }

        int fleeDist = Baritone.settings().fleeDistance.value;
        Vec3 away = ctx.player().position().subtract(closest.position()).normalize().scale(fleeDist);
        BlockPos fleePos = new BlockPos(
                (int) (ctx.player().position().x + away.x),
                (int) ctx.player().position().y,
                (int) (ctx.player().position().z + away.z)
        );

        return new GoalNear(fleePos, 5);
    }

    @Override
    public void onLostControl() {
        stopEating();
        state = State.IDLE;
        eatTicks = 0;
    }

    @Override
    public String displayName0() {
        return "Hunger/Health";
    }

    @Override
    public double priority() {
        return 10.0;
    }

    @Override
    public boolean isTemporary() {
        return true;
    }

    private enum State {
        IDLE, EATING, FLEEING
    }
}

// =====================================================================
// CombatProcess  (priority 9.5)
//
// Melee combat against hostile mobs. Only engages mobs that are within
// 4.5 blocks regardless of aggro state (in-your-face defense). For mobs
// between 4.5 and 10 blocks, only attacks if the mob is actively
// targeting the player (matching vanilla aggro range). This prevents
// constantly interrupting mining to fight cave spiders in the walls.
//
// Combat flow:
//  1. Within 4 blocks: face mob, hold left-click, alternate strafe
//     every 10 ticks
//  2. Within 10 blocks and target acquired: path toward mob
//  3. Outside thresholds or mob not aggroed: DEFER, do nothing
// =====================================================================

package baritone.process;

import baritone.Baritone;
import baritone.api.pathing.goals.Goal;
import baritone.api.pathing.goals.GoalNear;
import baritone.api.process.PathingCommand;
import baritone.api.process.PathingCommandType;
import baritone.api.utils.Rotation;
import baritone.api.utils.input.Input;
import baritone.utils.BaritoneProcessHelper;
import net.minecraft.core.BlockPos;
import net.minecraft.world.entity.Entity;
import net.minecraft.world.entity.LivingEntity;
import net.minecraft.world.entity.Mob;
import net.minecraft.world.entity.monster.Enemy;
import net.minecraft.world.phys.Vec3;

import java.util.List;
import java.util.stream.Collectors;

public class CombatProcess extends BaritoneProcessHelper {

    private State state = State.IDLE;
    private Entity target;
    private int strafeTicks = 0;
    private boolean strafeRight = true;

    private static final double ATTACK_RANGE = 4.0;
    private static final double APPROACH_RANGE = 10.0;
    private static final double IMMEDIATE_AGGRO_RANGE = 4.5;

    public CombatProcess(Baritone baritone) {
        super(baritone);
    }

    @Override
    public boolean isActive() {
        if (ctx.player() == null || ctx.world() == null) {
            return false;
        }
        LivingEntity target = findTarget();
        if (target != null) {
            double dist = ctx.player().distanceTo(target);
            if (dist < IMMEDIATE_AGGRO_RANGE) {
                return true;
            }
            if (dist < APPROACH_RANGE && isTargetingPlayer(target)) {
                return true;
            }
        }
        if (state == State.ATTACKING) {
            state = State.IDLE;
            releaseInputs();
        }
        return false;
    }

    @Override
    public PathingCommand onTick(boolean calcFailed, boolean isSafeToCancel) {
        LivingEntity target = findTarget();
        if (target == null) {
            state = State.IDLE;
            releaseInputs();
            return new PathingCommand(null, PathingCommandType.DEFER);
        }

        this.target = target;
        double dist = ctx.player().distanceTo(target);

        if (dist < ATTACK_RANGE) {
            return handleMeleeAttack(target);
        } else if (isTargetingPlayer(target)) {
            return handleApproach(target);
        }

        state = State.IDLE;
        releaseInputs();
        return new PathingCommand(null, PathingCommandType.DEFER);
    }

    private PathingCommand handleMeleeAttack(LivingEntity target) {
        state = State.ATTACKING;

        Vec3 targetPos = target.position();
        Vec3 playerPos = ctx.player().position();
        Vec3 diff = targetPos.subtract(playerPos);

        float yaw = (float) Math.toDegrees(Math.atan2(-diff.x, diff.z));
        float pitch = (float) Math.toDegrees(-Math.atan2(diff.y, Math.sqrt(diff.x * diff.x + diff.z * diff.z)));

        baritone.getLookBehavior().updateTarget(new Rotation(yaw, pitch), false);
        baritone.getInputOverrideHandler().setInputForceState(Input.CLICK_LEFT, true);

        strafeTicks++;
        if (strafeTicks > 10) {
            strafeRight = !strafeRight;
            strafeTicks = 0;
        }
        baritone.getInputOverrideHandler().setInputForceState(
                strafeRight ? Input.MOVE_RIGHT : Input.MOVE_LEFT, true
        );

        return new PathingCommand(null, PathingCommandType.REQUEST_PAUSE);
    }

    private PathingCommand handleApproach(LivingEntity target) {
        state = State.APPROACHING;
        releaseInputs();

        Goal goal = new GoalNear(target.blockPosition(), (int) ATTACK_RANGE - 1);
        return new PathingCommand(goal, PathingCommandType.SET_GOAL_AND_PATH);
    }

    private void releaseInputs() {
        baritone.getInputOverrideHandler().setInputForceState(Input.CLICK_LEFT, false);
        baritone.getInputOverrideHandler().setInputForceState(Input.MOVE_RIGHT, false);
        baritone.getInputOverrideHandler().setInputForceState(Input.MOVE_LEFT, false);
    }

    private LivingEntity findTarget() {
        int range = Baritone.settings().threatRange.value;
        final double rSq = (double) range * range;

        List<LivingEntity> threats = ctx.entitiesStream()
                .filter(e -> e instanceof LivingEntity && e.isAlive()
                        && e != ctx.player()
                        && e.distanceToSqr(ctx.player()) < rSq
                        && isHostile(e))
                .map(e -> (LivingEntity) e)
                .collect(Collectors.toList());

        if (threats.isEmpty()) {
            return null;
        }

        LivingEntity closest = threats.get(0);
        double minDist = ctx.player().distanceTo(closest);
        for (int i = 1; i < threats.size(); i++) {
            double d = ctx.player().distanceTo(threats.get(i));
            if (d < minDist) {
                minDist = d;
                closest = threats.get(i);
            }
        }
        return closest;
    }

    private boolean isHostile(Entity entity) {
        if (entity instanceof Enemy) {
            return true;
        }
        if (entity instanceof Mob) {
            Mob mob = (Mob) entity;
            return mob.getLastHurtByMob() == ctx.player() || mob.getTarget() == ctx.player();
        }
        return false;
    }

    private boolean isTargetingPlayer(Entity entity) {
        if (entity instanceof Mob) {
            Mob mob = (Mob) entity;
            return mob.getTarget() == ctx.player() || mob.getLastHurtByMob() == ctx.player();
        }
        return false;
    }

    @Override
    public void onLostControl() {
        releaseInputs();
        state = State.IDLE;
        target = null;
        strafeTicks = 0;
    }

    @Override
    public String displayName0() {
        if (target != null) {
            return "Fighting " + target.getName().getString();
        }
        return "Combat";
    }

    @Override
    public double priority() {
        return 9.5;
    }

    @Override
    public boolean isTemporary() {
        return true;
    }

    private enum State {
        IDLE, APPROACHING, ATTACKING
    }
}

// =====================================================================
// SleepProcess  (priority 8.0)
//
// Finds nearby beds and sleeps at night (time 12500-23500). Only uses
// existing placed beds  no bed placement yet (needs GUI interaction
// which is Phase 2 work).
//
// Key flow:
//  1. If night and a bed exists within 16 blocks: path to it
//  2. Right-click the bed to start sleeping
//  3. Wait until morning (getSleepTimer >= 100 or day time)
//  4. If bed is destroyed mid-sleep: scan for replacement, fall back
//     to IDLE
//  5. 300-tick timeout (15 seconds) to prevent indefinite blocking
//  6. If no bed found: returns DEFER, does NOT block  other processes
//     continue running through the night
// =====================================================================

package baritone.process;

import baritone.Baritone;
import baritone.api.pathing.goals.Goal;
import baritone.api.pathing.goals.GoalBlock;
import baritone.api.process.PathingCommand;
import baritone.api.process.PathingCommandType;
import baritone.api.utils.Rotation;
import baritone.api.utils.input.Input;
import baritone.utils.BaritoneProcessHelper;
import net.minecraft.core.BlockPos;
import net.minecraft.world.level.block.BedBlock;
import net.minecraft.world.phys.Vec3;
import net.minecraft.world.level.block.state.BlockState;
import net.minecraft.world.level.block.state.properties.BedPart;

public class SleepProcess extends BaritoneProcessHelper {

    private State state = State.IDLE;
    private BlockPos bedPos;
    private int sleepTicks;

    public SleepProcess(Baritone baritone) {
        super(baritone);
    }

    @Override
    public boolean isActive() {
        if (ctx.player() == null || ctx.world() == null) {
            return false;
        }

        if (state == State.SLEEPING) {
            return true;
        }

        if (state == State.GOING_TO_BED) {
            return true;
        }

        if (!shouldSleep()) {
            return false;
        }

        BlockPos existing = findNearbyBed();
        if (existing != null) {
            bedPos = existing;
            state = State.GOING_TO_BED;
            return true;
        }

        return false;
    }

    @Override
    public PathingCommand onTick(boolean calcFailed, boolean isSafeToCancel) {
        switch (state) {
            case GOING_TO_BED: {
                if (bedPos == null) {
                    state = State.IDLE;
                    return new PathingCommand(null, PathingCommandType.DEFER);
                }

                double dist = ctx.player().distanceToSqr(
                        bedPos.getX() + 0.5, bedPos.getY() + 0.5, bedPos.getZ() + 0.5
                );
                if (dist < 9) {
                    state = State.SLEEPING;
                    sleepTicks = 0;
                    break;
                }

                Goal goal = new GoalBlock(bedPos);
                return new PathingCommand(goal, PathingCommandType.SET_GOAL_AND_PATH);
            }

            case SLEEPING: {
                if (!shouldSleep() && !ctx.player().isSleeping()) {
                    stopSleeping();
                    return new PathingCommand(null, PathingCommandType.DEFER);
                }

                if (!ctx.player().isSleeping()) {
                    if (bedPos == null || !isStillBed(bedPos)) {
                        BlockPos nearby = findNearbyBed();
                        if (nearby != null) {
                            bedPos = nearby;
                        } else {
                            // Bed was destroyed or moved  give up
                            stopSleeping();
                            return new PathingCommand(null, PathingCommandType.DEFER);
                        }
                    }

                    if (sleepTicks < 2) {
                        Vec3 bedCenter = new Vec3(bedPos.getX() + 0.5, bedPos.getY() + 0.5, bedPos.getZ() + 0.5);
                        Vec3 eyes = ctx.player().getEyePosition(1.0f);
                        Vec3 diff = bedCenter.subtract(eyes);
                        float yaw = (float) Math.toDegrees(Math.atan2(-diff.x, diff.z));
                        float pitch = (float) Math.toDegrees(-Math.atan2(diff.y, Math.sqrt(diff.x * diff.x + diff.z * diff.z)));
                        baritone.getLookBehavior().updateTarget(
                                new Rotation(yaw, pitch), true
                        );
                        baritone.getInputOverrideHandler().setInputForceState(Input.CLICK_RIGHT, true);
                    }

                    sleepTicks++;
                    if (sleepTicks >= 5) {
                        baritone.getInputOverrideHandler().setInputForceState(Input.CLICK_RIGHT, false);
                        sleepTicks = 0;
                        return new PathingCommand(null, PathingCommandType.REQUEST_PAUSE);
                    }
                } else {
                    baritone.getInputOverrideHandler().setInputForceState(Input.CLICK_RIGHT, false);

                    if (ctx.player().getSleepTimer() >= 100) {
                        stopSleeping();
                        return new PathingCommand(null, PathingCommandType.DEFER);
                    }
                }

                sleepTicks++;
                if (sleepTicks > 300) {
                    stopSleeping();
                }

                return new PathingCommand(null, PathingCommandType.REQUEST_PAUSE);
            }

            default:
                return new PathingCommand(null, PathingCommandType.DEFER);
        }
        return new PathingCommand(null, PathingCommandType.REQUEST_PAUSE);
    }

    private boolean shouldSleep() {
        if (!Baritone.settings().allowSleep.value) {
            return false;
        }
        if (ctx.player().isSleeping()) {
            return false;
        }
        return isNighttime();
    }

    private boolean isNighttime() {
        if (ctx.world() == null) {
            return false;
        }
        long time = ctx.world().getDayTime() % 24000;
        return time > 12500 && time < 23500;
    }

    private boolean isStillBed(BlockPos pos) {
        if (ctx.world() == null) {
            return false;
        }
        BlockState state = ctx.world().getBlockState(pos);
        return state.getBlock() instanceof BedBlock;
    }

    private BlockPos findNearbyBed() {
        int radius = 16;
        BlockPos center = ctx.playerFeet();
        for (int x = -radius; x <= radius; x++) {
            for (int y = -4; y <= 4; y++) {
                for (int z = -radius; z <= radius; z++) {
                    BlockPos pos = center.offset(x, y, z);
                    BlockState state = ctx.world().getBlockState(pos);
                    if (state.getBlock() instanceof BedBlock
                            && state.getValue(BedBlock.PART) == BedPart.HEAD) {
                        return pos;
                    }
                }
            }
        }
        return null;
    }

    private void stopSleeping() {
        baritone.getInputOverrideHandler().setInputForceState(Input.CLICK_RIGHT, false);
        state = State.IDLE;
        bedPos = null;
        sleepTicks = 0;
    }

    @Override
    public void onLostControl() {
        stopSleeping();
    }

    @Override
    public String displayName0() {
        return "Sleep";
    }

    @Override
    public double priority() {
        return 8.0;
    }

    @Override
    public boolean isTemporary() {
        return true;
    }

    private enum State {
        IDLE, GOING_TO_BED, SLEEPING
    }
}

// =====================================================================
// DeathRecoveryProcess  (priority 7.0)
//
// Records death position and paths back after respawn to recover items.
// Uses the existing Baritone death event system rather than polling
// health state.
//
// Death detection architecture:
//  - Implements IGameEventListener to receive onPlayerDeath()
//  - The death event is already fired by MixinClientPlayNetHandler
//    when ClientboundPlayerCombatKillPacket is received
//  - This is a definitive event, not a transitional state poll
//  - At event time, ctx.playerFeet() returns the correct death position
//    (the player entity is still valid during the death animation)
//
// Recovery flow:
//  1. Mixin catches death packet, fires GameEventHandler.onPlayerDeath()
//  2. DeathRecoveryProcess.onPlayerDeath() stores deathPos, sets
//     recovering = false
//  3. After respawn, isActive() checks: deathPos != null &&
//     !recovering && isAlive() -> start recovery if far from death
//  4. PathingCommand SET_GOAL_AND_PATH with GoalNear(deathPos, 2)
//  5. On arrival (distance < 9 blocks), clears state and DEFERs
//
// Edge cases handled:
//  - Death during recovery: onPlayerDeath() overwrites deathPos,
//    resets recovering, starts fresh recovery after respawn
//  - Respawn near death point (< 25 blocks): clears deathPos
//    (items dropped nearby, not worth pathfinding)
//  - Player not alive (death screen): isActive returns false, no
//    state change
// =====================================================================

package baritone.process;

import baritone.Baritone;
import baritone.api.event.listener.IGameEventListener;
import baritone.api.pathing.goals.Goal;
import baritone.api.pathing.goals.GoalNear;
import baritone.api.process.PathingCommand;
import baritone.api.process.PathingCommandType;
import baritone.utils.BaritoneProcessHelper;
import net.minecraft.core.BlockPos;

public class DeathRecoveryProcess extends BaritoneProcessHelper implements IGameEventListener {

    private BlockPos deathPos;
    private boolean recovering;

    public DeathRecoveryProcess(Baritone baritone) {
        super(baritone);
        baritone.getGameEventHandler().registerEventListener(this);
    }

    @Override
    public void onPlayerDeath() {
        if (ctx.player() != null && ctx.world() != null) {
            this.deathPos = ctx.playerFeet();
            this.recovering = false;
            logNotification("Died at " + deathPos.toShortString() + "! Will recover items...", true);
        }
    }

    @Override
    public boolean isActive() {
        if (ctx.player() == null || ctx.world() == null) {
            return false;
        }

        if (recovering && ctx.player().isAlive()) {
            double dist = distanceToDeathPos();
            if (dist < 9) {
                logNotification("Arrived at death point!", false);
                recovering = false;
                deathPos = null;
                return false;
            }
            return true;
        }

        if (deathPos != null && !recovering && ctx.player().isAlive()) {
            double dist = distanceToDeathPos();
            if (dist > 25) {
                logNotification("Recovering items from " + deathPos.toShortString() + "...", true);
                recovering = true;
                return true;
            }
            // Respawned right on top of death point  no recovery needed
            deathPos = null;
        }

        return false;
    }

    @Override
    public PathingCommand onTick(boolean calcFailed, boolean isSafeToCancel) {
        if (!recovering || deathPos == null) {
            return new PathingCommand(null, PathingCommandType.DEFER);
        }

        double dist = distanceToDeathPos();

        if (dist < 9) {
            logNotification("Arrived at death point!", false);
            recovering = false;
            deathPos = null;
            return new PathingCommand(null, PathingCommandType.DEFER);
        }

        Goal goal = new GoalNear(deathPos, 2);
        return new PathingCommand(goal, PathingCommandType.SET_GOAL_AND_PATH);
    }

    private double distanceToDeathPos() {
        if (deathPos == null) {
            return Double.MAX_VALUE;
        }
        return ctx.player().distanceTo(
                deathPos.getX() + 0.5, deathPos.getY(), deathPos.getZ() + 0.5
        );
    }

    @Override
    public void onLostControl() {
    }

    @Override
    public String displayName0() {
        return "Death Recovery";
    }

    @Override
    public double priority() {
        return 7.0;
    }

    @Override
    public boolean isTemporary() {
        return true;
    }
}
